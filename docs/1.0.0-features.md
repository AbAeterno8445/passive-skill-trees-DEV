# Version 1.0.0 features

### **Sidereal Tree Feature: Sidereal Artifact**

- New "Sidereal Artifact" large node, connected to many **Septentrional** (northern) artifact nodes, and **Meridional** (southern) artifact nodes.
- Septentrional artifacts provide a **condition** to fulfill in-game that generates an amount of **energy**. For example, Kill a monster -> Generates 3 energy.
- Meridional artifacts provide an effect that gets triggered once a certain energy threshold is reached, depending on the artifact. For example, 15 energy -> Gain 5% all stats for 5 seconds.
- Artifact nodes have unlock requirements before you can allocate them, akin to achievements ("Destroy 100 frozen monsters", etc.). Once unlocked, they remain unlocked for every character.
- You can initially only select 1 of each artifact. There are nodes that allow spending Crimson Starcores to allocate more Septentrional artifacts, up to 3, allowing you to have multiple energy-generating conditions active simultaneously.
- Does not support Dynamic Tree Mode, chosen artifact effects are locked to that run once it begins.

### **Sidereal Tree Feature: Crimson Convergence**

- New "Crimson Convergence" large node. Once allocated, press Allocate to open a menu of selectable buffs to be applied to runs.
- These buffs scale with the amount of Crimson Starcores your character has, although some of them still provide a small effect even if you have none.
- Buffs can be changed for free.
- Crimson Starcores are a resource that can be found as an uncommon reward for completing depth 15+ expeditions.
- Does not support Dynamic Tree Mode, chosen buff is locked to that run once it begins.
